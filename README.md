# FCC-Workshop-Tutorial

Use "launchme.sh" to run GUINEA-PIG on lxplus.

launchme.sh script and acc.dat file provided by Andrea Ciarma, INFN.

The arguments to the command 'guinea' select parameter sets in the acc.dat file.

e.g.

guinea FCCee_Z_4IP_29may24 FCCee_Z output

guinea FCCee_WW_4IP_29may24 FCCee_WW output

guinea FCCee_ZH_4IP_29may24 FCCee_ZH output

guinea FCCee_Top_4IP_29may24 FCCee_Top output
